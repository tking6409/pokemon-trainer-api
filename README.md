# Pokémon Trainer API
This is my Pokémon Trainer API project for my App Programming Interface Development class.
## About My Project
I created this API using Python, FastAPI, and SQLite. It allows users to create, view, update, and delete Pokémon trainers. Users can also add, view, and remove Pokémon from a trainer's team.
## Cloud Deployment
I uploaded my project to GitHub and deployed it using Render so my API can be accessed online.
